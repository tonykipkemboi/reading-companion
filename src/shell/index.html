Add your Nebius key to switch on explanations

Explanations are written by a model on Nebius Token Factory, and it needs your API key. Until then the app is only a browser.

  1. Create a key on Token Factory.
  2. Copy the key.
  3. Come back here and press "Use the key I copied".

Your key is saved on this computer only, in the app's settings file, and is sent to Nebius and nowhere else. When you ask a question, the text and address of the page you are on go to Nebius too, so it can write the answer.
